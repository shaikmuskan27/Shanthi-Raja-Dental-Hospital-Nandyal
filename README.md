# Shanthi Raja Dental Hospital - Nandyal

> **Where advanced dentistry meets genuine warmth.**

Official modern web application for **Shanthi Raja Dental Hospital**, located in Nandyal, Andhra Pradesh.

---

## 🌟 Overview & Key Features

- **Cinematic Silent Video Experience**: Full-width high-definition clinic overview video auto-playing smoothly with minimal dark scrim and playback toggle.
- **Interactive Navigation & Dropdown Menus**:
  - **About Us**: Hospital Overview, Meet Specialist Doctors, Hospital Standards.
  - **Services**: Painless Root Canal (RCT), Orthodontics & Braces, Dental Implants, Cosmetic Smile Makeovers, and View All 10 Services.
  - **Patient Info**: Patient Quick Portal, Online Priority Booking, FAQs & Insurance / EMI, Directions & Landmark.
- **Specialist Clinicians Section**:
  - **Dr. Balusa Rajeev (M.D.S., Endodontist)**: Specialist in painless root canal treatments, high-magnification optics, and rotary endodontics (1,500+ procedures).
  - **Dr. K. Prasanthi Lakshmi Devi (Dip. Orthodontics)**: Specialist in ceramic braces, clear aligners, and corrective jaw alignment.
  - Direct "Book with Doctor" buttons automatically pre-fill treatment & specialist fields in the booking section.
- **10 Comprehensive Dental Services with Filter Pills**:
  - Filter categories: *All Services (10)*, *Specialist RCT & Ortho*, *Implants & Crowns*, *Preventative & Kids*.
  - Every service card features an action button directly tied to the booking form.
- **End-to-End Online Appointment Scheduling**:
  - Form validation with automated date constraints.
  - Generates instant verified booking tickets (`REF: SRDH-2026-XXXX`).
  - One-click **"Add to Google Calendar"** integration.
  - One-click **"WhatsApp Receipt"** dispatching to the hospital front desk.
  - Form reset & multi-booking support.
- **Dr. Shanthi AI Voice Assistant**:
  - Real browser Text-To-Speech (`speechSynthesis`) and voice recognition.
  - Animated audio visualizer soundwaves.
  - Quick voice prompts for root canals, braces, emergencies, and hospital timings.
- **Patient Quick Portal**:
  - Search and verify appointments by mobile number or Reference ID.
  - Direct links to hospital WhatsApp help and reception hotline.
- **Hospital Timings & Landmark Location**:
  - **Hours**: Monday to Sunday: 10:00 AM – 9:00 PM (7 Days a Week).
  - **Location**: Doctors Complex, opp. HP Petrol Bunk, Priyanka Nagar, Farooq Nagar, Srinivasa Nagar, Nandyal, Andhra Pradesh 518501.
  - **Direct Line**: `090520 55148`

## 🚀 Getting Started

Simply open `index.html` or `code.html` in any modern web browser or serve via any static web server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```
